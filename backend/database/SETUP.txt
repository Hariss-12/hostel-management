HMS DATABASE SETUP (Windows / pgAdmin 4)

1. Start your local PostgreSQL service and open pgAdmin 4.
2. Create a database named hostel_management if it does not already exist.
3. Right-click hostel_management -> Query Tool. Confirm the query tab is connected to hostel_management (not the postgres maintenance database).
4. Open this folder's schema.sql in VS Code. Copy the entire file from the first line to the last line, paste it into Query Tool, press Ctrl+A, then F5.
5. Wait for Query complete / successful messages. Refresh Schemas -> public -> Tables.
6. Verify that users, students, hostels, rooms, beds, allocations, fees, payments, attendance, leaves, mess_menu, meal_opt_outs, complaints and notifications exist.

IMPORTANT
- Run the complete file, not only the final index statements.
- The script is transactional and non-destructive: it creates missing HMS tables and upgrades columns on an older partial students table.
- It does NOT drop tables or delete existing records. It is safe to run again.
- Guardian name and phone are optional. New/updated student years are restricted to 1-4.
- After configuring backend/.env and creating the admin account, run `npm run seed-demo` from the backend folder to populate showcase data.
- Demo accounts are for local showcase only. See the root README.md for demo login credentials.
